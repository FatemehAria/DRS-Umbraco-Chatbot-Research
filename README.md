# DRS Umbraco Chatbot Research

Evaluation scripts, benchmark datasets, and relevance experiments
for the chatbot used in the
[DRS Umbraco CMS](https://github.com/FatemehAria/DRS-Umbraco).

## Contents

- Embedding and reranking experiments
- Benchmark scripts
- Holdout evaluation results
- Offline environment probes

> Model binaries and production configuration are intentionally excluded.
